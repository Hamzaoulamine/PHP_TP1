### 2. Pourquoi passer par `localhost` ?
Il faut passer par `localhost` car le navigateur ne peut pas exécuter directement le code PHP. Il faut passer par le serveur Web local (Apache) qui traite le script PHP et génère le code HTML correspondant avant de l'envoyer au navigateur[cite: 1].
